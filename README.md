# 地底の竜 -XANADU-like-

『ザナドゥ』風の横スクロール・アクションRPGです。HTML5 Canvas と素の JavaScript だけで動きます（ビルド不要）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

ローカルサーバーで動かす場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

### 操作

| キー | 動作 |
| --- | --- |
| ← → | 移動（守護者の間では ↑↓ も移動） |
| ↑ ↓ | はしごの上り下り／扉・店に入る（↑）／板から飛び降りる（↓） |
| Z / Space | ジャンプ（空中でもう一度押すと二段ジャンプ。守護者の間では階段から出る） |
| X | 魔法 ／ Q 魔法の切り替え |
| D | つるはしで前のレンガを掘る（↓＋D で足元） |
| A / S | 薬／魔法の水を飲む |
| V | 道具（魔法の翼・砂時計など） |
| C / Enter | ステータス・装備の変更 |
| Esc / P | ポーズ（「ここで記録する」でどこでもセーブ） |

メニューは ↑↓ で選び、Z / Enter で決定、X / Esc で戻ります。

### スマホ・タブレット

タッチ端末では画面に十字キーとボタンが表示されます。縦向きでも横向きでも遊べます。

- 十字キー：移動（▲で扉に入る・はしごを登る、▼ではしごを降りる）
- 跳ぶ（Z）：ジャンプ（空中でもう一度で二段ジャンプ）・メニューの決定・守護者の間から出る
- 魔法（X）：魔法・メニューで戻る
- 掘る／切替：つるはし（▼を押しながらで足元）／魔法の切り替え
- 薬・水・道具・状態・≡（ポーズ）
- メニューは項目を直接タップしても選べ、右上の × で閉じられます

## ザナドゥ風のしくみ

ザナドゥの人気の理由と、それぞれをどう取り入れたかは [docs/xanadu-analysis.md](docs/xanadu-analysis.md) にまとめています。

- **有限の資源**: 迷宮の魔物は倒すと二度と現れません。経験値も金も限られています。
- **キャラメイク**: 王の支度金を、王城の訓練所での能力強化と装備のどちらに使うかを選びます。
- **熟練度**: 武器・鎧・盾・魔法は使うほど強くなります（最大 Lv9）。
- **寺院でレベルアップ**／**カルマ**: 罪なき精霊を倒すとカルマが増え、レベルを上げてもらえなくなります。
- **2つの視点**: 探索は横スクロール、守護者の間は見下ろし視点です。どちらも体当たりで戦います。
- **つるはしと隠し部屋**: レンガの壁を掘ると、隠された宝が見つかることがあります。
- **守護者と王冠**: 各層の守護者が落とす王冠を3つ集めると、竜の巣への扉が開きます。
- **食料**・**鍵**・**ドラゴンスレイヤー**

### セーブ

- **宿屋に泊まる**：全回復して記録。再開は宿屋の前から
- **どこでもセーブ**：ポーズメニュー（Esc／スマホは ≡）の「ここで記録する」で、その場所に記録。再開もその場所から
- 記録は1つだけで、新しく記録すると上書きされます。保存先はブラウザの中（`localStorage`）です

## 構成

```
index.html      画面とHUD
style.css       見た目
js/sprites.js   ドット絵（16x16の文字列定義）
js/data.js      武器・防具・魔法・道具・敵・訓練・経験値テーブル
js/maps.js      マップ（町は生成、迷宮はビルダー、守護者の間は手書き）
docs/           ザナドゥの分析メモ
js/game.js      ゲーム本体（物理・戦闘・AI・メニュー・描画）
js/touch.js     スマホ用のタッチ操作
linedraw/       ラインドローゲーム「エアポート・ライン」（下記）
```

### マップの作り方

`js/maps.js` の `makeDungeon(幅, 段数, m => { ... })` で迷宮を作ります。段 `l` は 2 マスの高さの通路で、その下が床です。

- `m.lad(l, x)` 段 `l` から `l+1` へのはしご
- `m.at(l, x, 記号)` 敵（`1`〜`9`、守護者 `X Y Z`）・アイテム（`$ ! * ? % & m G Q R L`）・扉（`a`〜`h`）・店（`K W A F S I T`）を置く
- `m.lock(l, x)` 鍵のかかった扉　`m.wall(l, x)` レンガの壁（掘れる。隠し部屋に使う）　`m.pit(l, x0, x1)` 床の穴　`m.spikes(l, x0, x1)` トゲ　`m.block(l, x0, x1)` 石ブロック（掘れない）

守護者の間のような見下ろし視点のエリアは、文字列の配列で直接書き、`AREAS` に `view: 'top'` を付けます。

扉どうしのつながりは `AREAS` の `links` で指定します（例: `{ b: ['d2', 'b'] }` は「扉 b から d2 の扉 b へ」）。

# エアポート・ライン（ラインドローゲーム）

`linedraw/index.html` を開くと遊べます。指やマウスで飛行機から線を引いて誘導し、滑走路に着陸させるゲームです。

- 飛行機をつかんでなぞると、その線に沿って飛びます（スマホでは複数の指で同時に描けます）
- **旅客機**（青・速い）は**長い滑走路**だけ、**プロペラ機**（オレンジ・遅い）は**短い滑走路**と**長い滑走路**のどちらにも着陸できます
- 滑走路には **▶ の矢印の向き**からしか進入できません。線が入口につながると色付きの線になり、着陸が決まります
- 画面の端で点滅する印は、もうすぐ飛行機が入ってくる場所です
- 飛行機どうしが近づくと赤い輪で警告。ぶつかったらゲームオーバー
- 着陸させるほど飛行機が増え、出てくる間隔も短くなります。ベスト記録はブラウザに保存されます
- **スピード調整**：×0.5〜×2 の6段階。右上の「×1」ボタン（押すたびに切り替え）、タイトル・ポーズ画面のボタン、キーボードの + / - で変えられます。飛行機の速さも出てくる間隔も、ゲーム全体が同じ倍率で速く・遅くなります（設定はブラウザに保存）
- Esc / P（スマホは右上の Ⅱ）でポーズ、♪ で音のオン・オフ

```
linedraw/index.html  画面
linedraw/style.css   見た目
linedraw/game.js     ゲーム本体（線の入力・飛行・着陸判定・衝突・描画）
```
