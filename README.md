# 地底の竜 -XANADU-like-

『ザナドゥ』風の横スクロール・アクションRPGです。HTML5 Canvas と素の JavaScript だけで動きます（ビルド不要）。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

ローカルサーバーで動かす場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

### 操作

| キー | 動作 |
| --- | --- |
| ← → | 移動 |
| ↑ ↓ | はしごの上り下り／扉・店に入る（↑）／板から飛び降りる（↓） |
| Z / Space | ジャンプ |
| X | 魔法（ファイア、MP 3） |
| A | 薬を飲む |
| S | 魔法の水を飲む |
| C / Enter | ステータス・装備の変更 |
| Esc / P | ポーズ |

メニューは ↑↓ で選び、Z / Enter で決定、X / Esc で戻ります。

## ザナドゥ風のしくみ

- **体当たりで攻撃**: 敵に向かって歩くと攻撃します。攻撃の間隔は AGI で決まります。
- **武器の熟練度**: 武器ごとに経験値があり、使うほど強くなります（最大 Lv9）。
- **寺院でレベルアップ**: 経験値がたまったら町の寺院でレベルを上げてもらいます。
- **カルマ**: 罪のない「さまよう精霊」を倒すとカルマが増えます。カルマがあると寺院でレベルを上げてもらえません（お布施で清められます）。
- **食料**: 迷宮では時間とともに食料が減り、なくなると HP が減っていきます。
- **鍵**: 鍵のかかった扉は鍵で開けます。鍵は迷宮で拾うか道具屋で買えます。
- **宿屋**: 泊まると全回復し、セーブされます（`localStorage`）。
- **ドラゴンスレイヤー**: 最深部の竜は、この剣でないと傷つけられません。

## 構成

```
index.html      画面とHUD
style.css       見た目
js/sprites.js   ドット絵（16x16の文字列定義）
js/data.js      武器・防具・敵・経験値テーブル
js/maps.js      マップ（町は生成、迷宮はビルダーで定義）
js/game.js      ゲーム本体（物理・戦闘・AI・メニュー・描画）
```

### マップの作り方

`js/maps.js` の `makeDungeon(幅, 段数, m => { ... })` で迷宮を作ります。段 `l` は 2 マスの高さの通路で、その下が床です。

- `m.lad(l, x)` 段 `l` から `l+1` へのはしご
- `m.at(l, x, 記号)` 敵（`1`〜`9`）・アイテム（`$ ! * ? % &`）・扉（`a`〜`h`）・店（`W A F I T`）を置く
- `m.lock(l, x)` 鍵のかかった扉　`m.pit(l, x0, x1)` 床の穴　`m.spikes(l, x0, x1)` トゲ　`m.block(l, x0, x1)` 石ブロック

扉どうしのつながりは `AREAS` の `links` で指定します（例: `{ b: ['d2', 'b'] }` は「扉 b から d2 の扉 b へ」）。
