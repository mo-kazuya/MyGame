# エアポート管制官（ラインドローゲーム）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/airport-controller/）。指やマウスで飛行機から線を引いて誘導し、滑走路に着陸させるゲームです。

- 飛行機をつかんでなぞると、その線に沿って飛びます（スマホでは複数の指で同時に描けます）
- **旅客機**（青・速い）は**長い滑走路**だけ、**プロペラ機**（オレンジ・遅い）は**短い滑走路**と**長い滑走路**のどちらにも着陸できます
- 滑走路には **▶ の矢印の向き**からしか進入できません。線が入口につながると色付きの線になり、着陸が決まります
- 画面の端で点滅する印は、もうすぐ飛行機が入ってくる場所です
- 飛行機どうしが近づくと赤い輪で警告。ぶつかったらゲームオーバー
- **ステージ制**：目標の機数を着陸させるとステージクリアで、次のステージへ進みます（全8ステージ）。ぶつかったらそのステージをやり直し
- 遊べるようになったステージはブラウザに保存され、タイトル画面から選べます

| ステージ | 目標 | 飛行機 | 滑走路 |
| --- | --- | --- | --- |
| 1〜2 | 5・8 機 | 旅客機のみ | 長い2本 |
| 3〜4 | 10・12 機 | 旅客機＋プロペラ機 | 長い2本＋短い1本 |
| 5〜6 | 12・15 機 | 旅客機＋プロペラ機 | 長い1本＋短い1本 |
| 7〜8 | 15・20 機 | 旅客機＋プロペラ機 | 長い1本だけ |

ステージの中身は `game.js` の `STAGES`（目標・プロペラ機の割合・滑走路・同時に飛ぶ機数・出現間隔）で、滑走路の位置は `RUNWAY_DEFS` で変えられます。
- **スピード調整**：×0.5〜×2 の6段階。右上の「×1」ボタン（押すたびに切り替え）、タイトル・ポーズ画面のボタン、キーボードの + / - で変えられます。飛行機の速さも出てくる間隔も、ゲーム全体が同じ倍率で速く・遅くなります（設定はブラウザに保存）
- Esc / P（スマホは右上の Ⅱ）でポーズ、♪ で音のオン・オフ

## 構成

```
index.html   画面
style.css    見た目
game.js      ゲーム本体（線の入力・飛行・着陸判定・衝突・描画）
thumb.png    トップページ用のサムネイル
```

リポジトリ全体のことや、他のゲームは [ルートの README](../README.md) を見てください。
