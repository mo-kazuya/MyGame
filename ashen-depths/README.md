# 灰の迷宮（ローグライク）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/ashen-depths/）。入るたびに形が変わる迷宮にもぐり、地下 26 階に眠る秘宝「灰炎の心臓」を手に入れて、生きて地上へ持ち帰るゲームです。ターン制で、一度倒れたらそれで終わりです。

ゲームのルールは PC-9801 版『ローグ』（1985）をもとにしています。名前・怪物・アイテムの呼び名・画像（12×12 のドット絵）はすべてオリジナルです。

## 遊び方

- 階段を見つけて `>` で下へ。地下 26 階で灰炎の心臓を拾ったら、階段で `<` を押して地上まで上り続けるとクリア
- 怪物に向かって進むと攻撃。床のアイテムは上を歩くと拾う
- お腹が減ると「空腹 → 衰弱 → 気絶寸前」と進み、最後は餓死。食料は大事に
- 薬・巻物・指輪・杖は、最初は色や材質しかわからない。使ってみるか、識別の巻物で正体がわかる。`c` で自分用の名前を付けられる
- 呪われた武器・鎧・指輪は外せない。解呪の巻物で解ける
- 隠し扉や罠は `s` で探す

### 操作（キーボード）

| キー | 動作 |
| --- | --- |
| 方向キー / テンキー / `h` `j` `k` `l` `y` `u` `b` `n` | 移動・攻撃（Shift を押しながらで走る） |
| `.` / テンキー 5 | 1 ターン休む |
| `s` | 罠・隠し扉を探す |
| `>` / `<` | 階段を下りる / 上る |
| `i` | 持ち物 |
| `e` `q` `r` | 食べる / 薬を飲む / 巻物を読む |
| `w` `W` `T` | 武器を持つ / 鎧を着る / 鎧を脱ぐ |
| `P` `R` | 指輪をはめる / 外す |
| `t` `z` | 投げる / 杖を振る（続けて方向） |
| `d` `c` `D` | 置く / 名前を付ける / 判明したアイテム一覧 |
| `^` | 罠の種類を調べる |
| `a` | 直前のコマンドをくり返す |
| `S` `Q` | 保存して中断 / 冒険をやめる |
| `?` `/` | 操作一覧 / 図鑑（記号と怪物 26 種） |
| Ctrl+R | メッセージ履歴 |

いまはキーボード専用です（スマホのタッチ操作には未対応）。

### 保存

`S` で保存して中断し、タイトルの「続きから」で再開できます。再開するとセーブは消えます（やり直しはできません）。殿堂（上位 10 件）も保存されます。`localStorage` のキーは `ashen_depths_` で始まります。

## 構成

```
index.html   ゲーム本体（HTML・CSS・JavaScript・ドット絵のデータをすべて 1 ファイルに収録）
thumb.png    トップページ用のサムネイル
```

怪物は `MONS`、アイテムは `WEAPONS`・`ARMORS`・`POTIONS`・`SCROLLS`・`RINGS`・`WANDS`、ドット絵は `SP`（1 文字 = 1 ドット、`p` が色の対応表）にまとまっています。秘宝の階は `AMULET_DEPTH` で変えられます。
