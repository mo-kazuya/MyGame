# 灰の迷宮（ローグライク）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/ashen-depths/）。入るたびに形が変わる迷宮にもぐり、地下 26 階に眠る秘宝「灰炎の心臓」を手に入れて、生きて地上へ持ち帰るゲームです。ターン制で、一度倒れたらそれで終わりです。

ゲームのルールは PC-9801 版『ローグ』（1985）をもとにしています。名前・怪物・アイテムの呼び名・画像（12×12 のドット絵）はすべてオリジナルです。

## 遊び方

- 階段を見つけたら、上に乗ると「下りますか？」と聞かれる。地下 26 階で灰炎の心臓を拾ったら、階段を上り続けて地上に出るとクリア
- 主人公は**向き**を持っている（足もとの黄色い矢印）。攻撃・投げる・杖を振るは、向いている方向に向かって行う
- 怪物に向かって進んでも攻撃できる。床のアイテムは上を歩くと拾う
- 道具はメニューの「道具」から選ぶだけで、食べる・飲む・読む・装備・投げる・置くなどができる
- お腹が減ると「空腹 → 衰弱 → 気絶寸前」と進み、最後は餓死。食料は大事に
- 薬・巻物・指輪・杖は、最初は色や材質しかわからない。使ってみるか、識別の巻物で正体がわかる。自分用の名前も付けられる
- 呪われた武器・鎧・指輪は外せない。解呪の巻物で解ける
- 隠し扉や罠は、足踏み（または空振り）でまわりを探すと見つかる

### 難易度

タイトル画面の「難易度」ボタンで選べます（冒険の途中では変えられません。選んだ難易度は殿堂の記録にも残ります）。

| 項目 | かんたん | ふつう | むずかしい |
| --- | --- | --- | --- |
| アイテムの識別 | 拾うと識別 | 使うまで不明 | 使うまで不明 |
| 強化アイテムの出現 | 2 倍 | ふつう | ふつう |
| 呪われた装備 | 少ない | ふつう | 多い |
| 食料の出現 | 多い | ふつう | 少ない |
| 怪物の攻撃力 | ×0.7 | ×1 | ×1.3 |
| 最初の最大 HP | 20 | 12 | 12 |

項目は 1 つずつ変えることもできます（「カスタム」になります）。識別は「最初から全部わかる」（薬・巻物・指輪・杖の種類がはじめから判明）も選べ、強化アイテムは 3 倍まで上げられます。強化アイテムとは、筋力増強・筋力回復・レベル上昇・大回復の薬、鎧強化・武器強化・識別・解呪の巻物、守護・怪力・器用・強撃・再生の指輪のことです。倍率を上げると、はじめから強化された武器・鎧・指輪も見つかりやすくなります。

操作は『風来のシレン』『トルネコの大冒険』を参考にした「向き＋攻撃ボタン＋メニュー」式です。ゲームパッドだけで最後まで遊べます。

### 操作（ゲームパッド）

PC やスマホにゲームパッドをつなぐだけで使えます（標準配置のコントローラー：Switch Pro / PS / Xbox など）。

| ボタン | 動作 |
| --- | --- |
| 十字キー / 左スティック | 移動・攻撃（押しっぱなしで歩き続ける） |
| 右ボタン（Switch A / PS ○ / Xbox B） | 攻撃（向いている方向）・決定 |
| 下ボタン（Switch B / PS × / Xbox A） | キャンセル・戻る。押しながら方向でダッシュ |
| 右ボタン ＋ 下ボタン | 足踏み（1 ターン休んで、まわりを探す） |
| 左ボタン（Switch Y / PS □ / Xbox X）＋ 方向 | その場で向きだけ変える。押して離すと隣の怪物の方を向く |
| 上ボタン（Switch X / PS △ / Xbox Y）/ START | メニュー（道具・足元・履歴・保存など） |
| R / RB ＋ 方向 | ななめ移動だけにする |
| L / LB | 足元（階段・拾う） |
| SELECT / BACK | 全体地図（スマホ表示のとき） |

決定とキャンセルの位置（右＝シレン式 / 下＝Xbox 式）は、タイトル画面かメニューで切り替えられます。メニューや「はい／いいえ」は十字キーで選んで決定します。

### 操作（スマホ・タッチ）

スマホやタブレットでは画面の下（横向きなら左右）に操作ボタンが出て、マップは主人公を中心に表示されます。

| ボタン | 動作 |
| --- | --- |
| 矢印（8 方向） | 移動・攻撃。押しっぱなしで連続移動 |
| 真ん中の「足踏み」 | 休んで、まわりを探す |
| 攻撃 | 向いている方向へ攻撃 |
| 向き → 矢印 | 向きだけ変える（真ん中なら隣の怪物の方を向く） |
| 走る → 矢印 | その方向へ走る |
| マップをタップ | タップした方向へ 1 歩 |
| メニュー / 足元 | 道具・保存など / 階段を下りる・拾う |
| 全体地図 / 繰り返す / 履歴 | 迷宮全体の表示切り替え / 直前の行動をくり返す / メッセージ履歴 |

### 保存

メニューの「中断して保存」（キーボードは `S`）で保存して中断し、タイトルの「続きから」で再開できます。再開するとセーブは消えます（やり直しはできません）。殿堂（上位 10 件）も保存されます。ゲームパッドの決定ボタンの設定と難易度も保存されます。`localStorage` のキーは `ashen_depths_` で始まります。

## 構成

```
index.html   ゲーム本体（HTML・CSS・JavaScript・ドット絵のデータをすべて 1 ファイルに収録）
thumb.png    トップページ用のサムネイル
```

怪物は `MONS`、アイテムは `WEAPONS`・`ARMORS`・`POTIONS`・`SCROLLS`・`RINGS`・`WANDS`、ドット絵は `SP`（1 文字 = 1 ドット、`p` が色の対応表）にまとまっています。秘宝の階は `AMULET_DEPTH` で変えられます。難易度の項目とプリセットは `DIFF_OPTS`・`DIFF_PRESETS` にあります。
