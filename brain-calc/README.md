# 計算道場（計算の脳トレ）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/brain-calc/）。5 つのモードで暗算の速さ・正確さ・記憶力を鍛える脳トレゲームです。

## モード

| モード | 内容 | 記録 |
| --- | --- | --- |
| スピード計算 | 60 秒でできるだけ多くの計算問題を解く。5 問連続正解ごとにコンボ | 正解数 |
| あなうめ計算 | `□ × 7 = 56` のように、□ に入る数を答える（逆算） | 正解数 |
| どっちが大きい？ | 左右 2 つの式のうち、答えが大きいほうを選ぶ（同じこともある） | 正解数 |
| 暗算リレー | 「はじめの数」に続けて `+5`・`×2`… が 1 つずつ出る。頭の中だけで計算をつなげ、最後の答えを入力。正解するたびに式が 1 つ増える（ライフ 3） | つなげた最高ステップ |
| 100マス計算 | たて・よこの数を計算してマスをうめるタイムを競う。たし算・ひき算・かけ算、25 マス・100 マス。ミス 1 つにつき +3 秒 | タイム |

難しさ（100マス計算以外）

- **かんたん**：1 桁のたし算・ひき算
- **ふつう**：2 桁のたし算・ひき算、九九のかけ算・わり算
- **むずかしい**：3 桁のたし算・ひき算、2 桁×1 桁・2 桁×2 桁、わり算、`46 + 7 × 2` のような「かけ算が先」の式

## 遊び方

- 下のテンキー（パソコンは数字キーでも可）で答えを入力します。**答えの桁数ぶん入れると自動で答え合わせ**します
  - `C` で全部消す、`⌫`（Backspace）で 1 文字消す
- タイトル画面の「答えの入力」で**手書き**を選ぶと、テンキーのかわりに手書きの枠が出ます（下の「手書き入力」）
- まちがえると正しい答えが表示され、結果画面で「まちがえた問題」を見直せます
- どっちが大きい？：下のボタンか式そのものをタップ（パソコンは ← → ↓ キー）
- 左上の Ⅱ（Esc）でポーズ、右上の ♪ で音のオン・オフ
- 結果に応じて称号（たまご → ひよこ → 見習い → 一人前 → 達人 → 計算名人）がもらえます

## 手書き入力

- 枠に数字を **1 つずつ** 書きます。指（マウス）を離して 0.4 秒たつと 1 文字として読み取り、答えの欄に入ります
- 2 桁以上は、前の字の右どなりに続けて書いてもかまいません（前の字と横に重ならない線を書くと、前の字が確定します）
- 読み取りがゆれたとき（例：4 を 6 と読んだが、4 の可能性も 15% 以上あった）は、正しい数字として扱います
- タイトル画面の「手書きのためし書き」で、自分の字がどう読まれるか（上位 3 つの候補と確からしさ）を試せます
- 手書きはテンキーより時間がかかるので、**自己ベストはテンキーと分けて**記録します
- 読み取りはブラウザの中だけで行います（通信なし）。28×28 の画像にして小さなニューラルネット（約 4.7 万パラメータ）で判定します

読み取りの精度（学習に使っていない 14 人の手書き 3498 字、ゲームと同じ JavaScript で測定）：1 文字 **99.1%**。まちがえやすいのは 4→6、9→3、9→7 です。ただしこのデータはタブレットにペンで書いたものなので、スマホに指で書くと、字の癖によってはこれより下がることがあります。

モデルの作りかたは [`tools/README.md`](tools/README.md) を見てください。学習には MNIST（Yann LeCun, Corinna Cortes, Christopher J.C. Burges）と UCI Machine Learning Repository の Pen-Based Recognition of Handwritten Digits（E. Alpaydin, F. Alimoglu）を使っています。

モード・難しさごとの自己ベスト、連続トレーニング日数、今日の正解数はブラウザに保存されます（`localStorage` のキーは `brain.` で始まります）。

制限時間・称号の目安・問題の作りかたは `game.js` の `TIME_LIMIT`・`RANK_TH`・`GRID_TH`・`binary` などで変えられます。

## 構成

```
index.html   画面（上の帯・問題の黒板・テンキー）
style.css    見た目
game.js      ゲーム本体（問題づくり・各モード・入力・記録・音）
handwriting.js        手書き数字の読み取り（線 → 画像の前処理、ニューラルネットの計算）
handwriting-model.js  読み取りに使うニューラルネットの重み（tools/ で作る）
tools/       手書きモデルを作り直すための道具（遊ぶだけなら不要）
thumb.png    トップページ用のサムネイル
```

リポジトリ全体のことや、他のゲームは [ルートの README](../README.md) を見てください。
