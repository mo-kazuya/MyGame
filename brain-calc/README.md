# 計算道場（計算の脳トレ）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/brain-calc/）。5 つのモードで暗算の速さ・正確さ・記憶力を鍛える脳トレゲームです。

## モード

| モード | 内容 | 記録 |
| --- | --- | --- |
| スピード計算 | 60 秒でできるだけ多くの計算問題を解く。5 問連続正解ごとにコンボ | 正解数 |
| あなうめ計算 | `□ × 7 = 56` のように、□ に入る数を答える（逆算） | 正解数 |
| どっちが大きい？ | 左右 2 つの式のうち、答えが大きいほうを選ぶ（同じこともある） | 正解数 |
| 暗算リレー | 「はじめの数」に続けて `+5`・`×2`… が 1 つずつ出る。頭の中だけで計算をつなげ、最後の答えを入力。正解するたびに式が 1 つ増える（ライフ 3） | つなげた最高ステップ |
| 100マス計算 | たて・よこの数を計算してマスをうめるタイムを競う。たし算・ひき算・かけ算、25 マス・100 マス。ミス 1 つにつき +3 秒 | タイム |

難しさ（100マス計算以外）

- **かんたん**：1 桁のたし算・ひき算
- **ふつう**：2 桁のたし算・ひき算、九九のかけ算・わり算
- **むずかしい**：3 桁のたし算・ひき算、2 桁×1 桁・2 桁×2 桁、わり算、`46 + 7 × 2` のような「かけ算が先」の式

## 遊び方

- 下のテンキー（パソコンは数字キーでも可）で答えを入力します。**答えの桁数ぶん入れると自動で答え合わせ**します
  - `C` で全部消す、`⌫`（Backspace）で 1 文字消す
- まちがえると正しい答えが表示され、結果画面で「まちがえた問題」を見直せます
- どっちが大きい？：下のボタンか式そのものをタップ（パソコンは ← → ↓ キー）
- 左上の Ⅱ（Esc）でポーズ、右上の ♪ で音のオン・オフ
- 結果に応じて称号（たまご → ひよこ → 見習い → 一人前 → 達人 → 計算名人）がもらえます

モード・難しさごとの自己ベスト、連続トレーニング日数、今日の正解数はブラウザに保存されます（`localStorage` のキーは `brain.` で始まります）。

制限時間・称号の目安・問題の作りかたは `game.js` の `TIME_LIMIT`・`RANK_TH`・`GRID_TH`・`binary` などで変えられます。
