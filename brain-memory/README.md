# 記憶道場（記憶の脳トレ）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/brain-memory/）。「覚える時間」のあとに「思い出す時間」がある、3 つのモードで記憶力を鍛える脳トレゲームです。

## モード

| モード | 覚える | 思い出す | 記録 |
| --- | --- | --- | --- |
| 単語おぼえ書き | 並んだ単語を 2 分で覚える | 3 分で、覚えた単語を思い出せるだけ入力する（順番は自由） | 思い出せた数 |
| 数字マス記憶 | マスに並んだ数字（1〜9）と場所を覚える | 空になったマスに数字を穴埋めする | 合っていたマスの数 |
| ペア記憶 | 「田中さん ― カレー」のような組み合わせを覚える | 片方を見て、相手を 4 択から選ぶ | 正解数 |

難しさ

| | 単語おぼえ書き | 数字マス記憶 | ペア記憶 |
| --- | --- | --- | --- |
| かんたん | 15 個 | 3×3（覚える 30 秒・穴埋め 60 秒） | 6 組（覚える 60 秒） |
| ふつう | 20 個 | 4×4（60 秒・90 秒） | 8 組（90 秒） |
| むずかしい | 30 個 | 5×5（90 秒・120 秒） | 12 組（120 秒）。相手から元を当てる「逆から」の問題もまざる |

単語おぼえ書きの時間はどの難しさでも「覚える 2 分・書き出す 3 分」です。

## 遊び方

- 覚え終わったら「覚えた！」で、時間が残っていても思い出す画面へ進めます（結果に覚えた時間が出ます）
- **単語おぼえ書き**：入力欄に単語を入れて Enter（または「入れる」）。スペースや「、」で区切ってまとめて入れても OK
  - ひらがな・カタカナ・漢字のどれで書いても正解です（例：「ねこ」「ネコ」「猫」）。全角・半角の違いも気にしなくて大丈夫です
  - 入れた単語はタップで消せます。答え合わせまで正解かどうかは出ません
  - 結果画面で、思い出せた単語・わすれた単語・リストになかった単語が見られます
- **数字マス記憶**：マスをタップしてえらび、下の数字ボタンで入れます。入れると次のマスへ進みます（PC は数字キー・矢印キー・Backspace）
  - 結果画面で、まちがえたマスは右下に正しい数字が出ます
- **ペア記憶**：テーマ（人と好きな食べ物・人と部屋番号・物と色・物としまった場所・人と出身地）は毎回ランダム。選択肢はどれも覚えた組の中のものです（PC は 1〜4 キー）
- 左上の Ⅱ（Esc）でポーズ（ポーズ中は画面が隠れます）、右上の ♪ で音のオン・オフ
- 正解率に応じて称号（たまご → ひよこ → 見習い → 一人前 → 達人 → 記憶名人）がもらえます

モード・難しさごとの自己ベスト、連続トレーニング日数、今日おぼえた数はブラウザに保存されます（`localStorage` のキーは `memory.` で始まります）。

問題の量・時間は `game.js` の `CONF`、称号の目安は `RANK_PCT`、出てくる単語やペアのテーマは `words.js` で変えられます。

## 構成

```
index.html   画面（上の帯・問題の黒板）
style.css    見た目
words.js     単語おぼえ書きの単語と、ペア記憶のテーマ
game.js      ゲーム本体（問題づくり・各モード・入力・記録・音）
thumb.png    トップページ用のサムネイル
```
