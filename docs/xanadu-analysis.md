# ザナドゥの人気の理由と、本作への取り入れ方

『ザナドゥ（XANADU: Dragon Slayer II）』は 1985 年に日本ファルコムが発売し、木屋善夫さんが手がけたアクションRPGです。国産PCゲームとして約 40 万本を売り上げた大ヒット作です。
このメモでは、人気の理由を「仕組み」の面から整理し、本作（地底の竜）でどう再現したかを対応づけます。

## 1. 人気の理由（分析）

### ① 「有限の資源」が生む戦略性 ― いちばんの核
敵の総数があらかじめ決まっていて、倒した敵は二度と現れません。そのため **経験値もお金も有限** です。
- 「レベル上げのための稼ぎ」ができないので、限られた資源を何に使うかという **配分の判断** がゲームの中心になる。
- どの敵と戦い、どの敵を避けるか。お金を装備に回すか、能力に回すか、食料に回すか。一つひとつの選択に重みがある。
- その結果、**プレイヤーごとに攻略法が違う** という語りたくなる体験が生まれ、口コミで広がった。

### ② 自由度の高いキャラクターメイキング
最初にもらうお金を訓練（能力値）と装備に振り分けます。剣士型にするか、魔法型にするか、守りを固めるかを自分で決めます。
有限の資源と組み合わさって、「自分だけのキャラ」を育てる実感が強くなっています。

### ③ 熟練度システム ―「使い慣れた道具」が強い
武器（や防具・魔法）には熟練度があり、使うほど強くなります。**使い慣れた剣が、買ったばかりの上位の剣より強い** こともあります。
「新しい装備をすぐ買えばいい」という単純な話にならず、乗り換える時期を考える楽しさがあります。

### ④ カルマ（業）― 戦う相手を選ばせる倫理システム
罪のない存在を殺すとカルマが増え、レベルを上げてもらえなくなります。経験値が有限なので「全部倒す」が最適とは限らず、**倒してはいけない相手** が判断にもう一層の深みを加えています。

### ⑤ アクションとRPGの融合、2つの視点
探索は横スクロール、戦闘は見下ろし視点、と画面が切り替わります。どちらも **体当たり** によるリアルタイム戦闘です。
ただしダメージは能力値で決まるので、腕前よりも **育成と準備** が勝敗を分けます。アクションが苦手な人でも戦略で勝てるバランスです。

### ⑥ 広大な迷宮と隠された謎、助言のない探索
10 層の地下迷宮を、ほとんど説明なしに探索します。ゲーム内に助言をくれる人はおらず、物語の説明もほぼありません。
閉じた空間でありながら、**攻略の順番を自分で決められる自由** と **隠し要素の多さ** が「地図を描きながら遊ぶ」熱中を生みました。
つるはし（マトック）で壁を掘って新しい道や隠し部屋を見つける、という遊びも象徴的です。

### ⑦ 明確な目標：守護者・王冠・伝説の剣
各層のボスを倒して王冠を集め、聖剣ドラゴンスレイヤーで最後の敵に挑みます。
自由な探索の中にも、**はっきりした中間目標と最終目標** があって迷子になりにくい構造です。

### ⑧ サバイバル要素（食料）
時間とともに食料が減り、尽きると体力が減っていきます。迷宮に長くいるほど不利になるので、**帰り道とペース配分** を常に考えることになります。

## 2. 本作への取り入れ

| 原作の特徴 | 本作での実装 |
| --- | --- |
| ① 有限の敵・資源 | 迷宮の魔物は倒すと **二度と復活しない**（セーブにも記録）。HUD に「魔物 残り N/M」を表示。経験値と金の総量は固定 |
| ② キャラメイク | 王から **支度金 600G**。町の **王城・訓練所** で STR/DEF/AGI/INT/最大HP を金で鍛えられる（回数ごとに高くなる）。装備との取り合いになる |
| ③ 熟練度 | **武器・鎧・盾・魔法** それぞれに熟練度（Lv0〜9）。武器は攻撃で、防具は被弾で、魔法は命中で上がる |
| ④ カルマ | 「さまよう精霊」を倒すとカルマ +3。カルマがあると寺院でレベルを上げてもらえない。お布施で清められる |
| ⑤ 2つの視点・体当たり | 探索は横スクロール。**守護者の間は見下ろし視点** に切り替わる。戦闘はどちらも体当たり |
| ⑥ 隠し要素・掘削 | **つるはし**（D キー）でレンガを掘れる。各層の壁の向こうに **隠し部屋**（金・薬・命の霊薬・魔法の翼）。床を掘って下の段へ近道も可能 |
| ⑥ 説明の少なさ | ヒントは店の人の一言程度。隠し部屋の場所は示さない |
| ⑦ 守護者と王冠 | 各層の **守護者**（キングスライム／ミノタウロス／リッチ）が王冠を落とす。**王冠3つで竜の巣の扉が開く** |
| ⑦ 伝説の剣 | 竜は **ドラゴンスレイヤー** でしか傷つかない |
| ⑧ 食料 | 迷宮では食料が減り、尽きると HP が減る |
| 道具の多彩さ | 魔法の翼（町へ帰還）、砂時計（時間停止）、命の霊薬（自動で復活）、ランプ（暗い第3層を照らす） |
| 魔法 | ファイア／ニードル（貫通）／サンダー（8方向）。威力は INT とレベルと熟練度で決まる |

## 3. バランスの目安
- 全部の魔物を倒したときの総経験値は約 1,230 で、最大でレベル 8 前後になる。竜にはレベル 6〜7 程度でも挑める。
- 敵が落とす金と拾える金の合計は約 2,700G。すべての装備・訓練・道具は買えないので、何を選ぶかが問われる。
- 店で鍵を買えば守護者を避けて進むこともできる。ただし王冠がそろわないと竜の巣には入れない。
