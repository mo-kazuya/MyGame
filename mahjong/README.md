# 月夜の雀荘（4人打ちリーチ麻雀）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/mahjong/）。あなたと CPU 3人で打つ、ふつうのリーチ麻雀です。

## 遊び方

- 持ち点 25000点。**東風戦**（東1〜4局）か **半荘戦**（南4局まで）を選べます。だれかが 0点未満になったら終わり
- 自分の番は 1 枚ツモって 1 枚切ります
  - パソコン：切りたい牌をクリック（マウスを乗せると牌が持ち上がります）
  - スマホ：切りたい牌を 2 回タップ（1 回目で持ち上がり、2 回目で切る）
- 和了れるとき・鳴けるときは手牌の上にボタンが出ます：**ツモ・ロン・リーチ・ポン・チー・カン・スキップ**
  - リーチを押すと、切ってテンパイになる牌だけが明るくなるので、その中から切ります。リーチ後のツモ切りは自動
  - チーのしかたが何通りかあるときは、ボタンに使う牌が描いてあります
- 右上の ≡ でメニュー（鳴きの確認をしない・ヒント・CPU の速さ・タイトルへ）、♪ で音のオン・オフ
- **待ちのヒント**（タイトル画面で切り替え）：切るとテンパイになる牌に ▼ が付き、その牌を選ぶと待ちが出ます。テンパイ中は待ち牌とフリテンかどうかを表示します

### ルール

| 項目 | 内容 |
| --- | --- |
| 役 | 1翻〜役満までの一般的な役（タイトルの「遊び方・役一覧」に一覧） |
| ドラ | 表ドラ・カンドラ（カンするとすぐめくる）・裏ドラ・赤ドラ（各色の 5 を 1 枚ずつ、なしも選べる） |
| 鳴き | ポン・チー・明槓・暗槓・加槓。食いタン・後付けあり。喰い替えなし |
| ロン | ダブロンなし（頭ハネ）。フリテン（捨て牌・見逃し・リーチ後の見逃し）あり。槍槓あり |
| 流局 | 荒牌流局のみ（ノーテン罰符 3000点）。途中流局・流し満貫はなし |
| 連荘 | 親が和了るかテンパイで連荘。オーラスの親がトップなら終了（あがりやめ） |
| 終局 | 西入なし。残った供託はトップへ |

役満は複合しても数えますが、ダブル役満（四暗刻単騎・国士十三面など）はなしで 1 倍です。

### モード

- **フリー対局**：9人のキャラクターから相手を 3 人選んで打ちます（「おまかせ」でランダム）。東風戦か半荘戦を選べます
- **トーナメント**：予選 → 準決勝 → 決勝の 3 戦（どれも東風戦）。予選・準決勝は 2 位以内で勝ち上がり、決勝は 1 位で優勝。勝ち上がるほど相手が強くなり、決勝には★5 のシノブが必ず出ます。1 戦ごとに進み具合を保存します

### キャラクター（CPU）

基本は牌効率（シャンテン数と受け入れ枚数）で切る牌を決め、リーチを受けたら現物・スジ・字牌などの安全な牌で守ります。そのうえで一人ひとり打ち方の癖があります。

| 名前 | 強さ | 打ち方 | 癖 |
| --- | --- | --- | --- |
| ミオ | ★ | はじめたて | ときどき効率の悪い牌を切る。リーチされてもオリない |
| サキ | ★★ | タンヤオ速攻 | 1・9・字牌から先に切り、食いタンで早和了り |
| フユ | ★★ | 七対子好き | 対子が多いと七対子をめざす。役牌のポン以外は鳴かない |
| ハル | ★★ | 鳴き屋 | 役がありそうならどんどん鳴く。手牌が一色に寄ったら染め手 |
| ナツ | ★★ | リーチ一直線 | 役牌のポン以外は鳴かず、テンパイしたら必ずリーチ。押しが強い |
| アキ | ★★★ | 慎重派 | リーチされたら 1 シャンテンでもオリる。高い手や待ちが悪い手はダマ |
| ゴウ | ★★★ | 高打点派 | ドラ・役牌を大事にして染め手も狙う。高い手なら押す。跳満級はダマ |
| リン | ★★★ | バランス型 | 癖の少ない標準的な打ち方 |
| シノブ | ★★★★★ | 雀豪 | 下の「強い思考」で打つ |

**シノブの強い思考**（`js/game.js` の `strongDiscard` など）

- **先読み**：1 シャンテンのとき、有効牌を引いたあと最善に切った場合の待ち枚数まで数え、良い形に育つ切り方を選ぶ。テンパイでは待ちの残り枚数と役の有無を見る（鳴いて役なしのテンパイは避ける）
- **手の値段**：ドラ・赤ドラ・役牌の対子を残す価値を、受け入れ枚数と比べて決める
- **危険度の読み**：現物・スジに加えて壁（ノーチャンス・ワンチャンス）を読み、リーチ者だけでなく 3 副露や染め手・ドラの多い仕掛けも警戒する
- **押し引き**：「和了れそうな見込み × 自分の手の値段」と「放銃しそうな見込み × 相手の手の値段」を切る牌ごとに比べて、押すか降りるかを決める
- **リーチ判断**：役があって満貫級ならダマ、終盤で役があるならダマ、それ以外はリーチ。鳴きはテンパイが近いかドラがあるときだけ

癖は `js/chars.js` の `style` の値で変えられます。キャラクターを足すのもここに 1 件書くだけです。

### 保存

- 局のはじめごとに途中経過（点数・局・本場・供託）を保存します。タイトルの「続きから」で、その局のはじめから再開できます（牌の並びは新しく配りなおし）
- 設定・戦績（順位の回数・トーナメントの優勝回数）・トーナメントの進み具合も保存します。`localStorage` のキーは `mahjong.` で始まります

## 構成

```
index.html     画面（キャンバス・ボタン置き場）
style.css      見た目（ボタン・タイトル・結果画面）
js/rules.js    ルール計算（シャンテン数・待ち・役・符・点数）。node でも動く
js/chars.js    キャラクター（名前・強さ・打ち方の癖）とトーナメントの組み合わせ
js/game.js     進行・CPU の思考・描画・操作・画面
tools/test.js  rules.js のテスト（node mahjong/tools/test.js）
thumb.png      トップページ用のサムネイル
```

牌の絵はすべてキャンバスで描いています（画像ファイルなし）。`index.html#auto` を開くと 4 人とも CPU で高速に対局し続けます（動作確認用）。`#auto=shinobu,rin,rin,rin` のように 4 人のキャラクターを指定でき、開発者ツールで `window.__rank` を見るとキャラごとの順位の回数がわかります。

リポジトリ全体のことや、他のゲームは [ルートの README](../README.md) を見てください。
