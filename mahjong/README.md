# 月夜の雀荘（4人打ちリーチ麻雀）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/mahjong/）。あなたと CPU 3人で打つ、ふつうのリーチ麻雀です。

## 遊び方

- 持ち点 25000点。**東風戦**（東1〜4局）か **半荘戦**（南4局まで）を選べます。だれかが 0点未満になったら終わり
- 自分の番は 1 枚ツモって 1 枚切ります
  - パソコン：切りたい牌をクリック（マウスを乗せると牌が持ち上がります）
  - スマホ：切りたい牌を 2 回タップ（1 回目で持ち上がり、2 回目で切る）
- 和了れるとき・鳴けるときは手牌の上にボタンが出ます：**ツモ・ロン・リーチ・ポン・チー・カン・スキップ**
  - リーチを押すと、切ってテンパイになる牌だけが明るくなるので、その中から切ります。リーチ後のツモ切りは自動
  - チーのしかたが何通りかあるときは、ボタンに使う牌が描いてあります
- 右上の ≡ でメニュー（鳴きの確認をしない・ヒント・CPU の速さ・タイトルへ）、♪ で音のオン・オフ
- **待ちのヒント**（タイトル画面で切り替え）：切るとテンパイになる牌に ▼ が付き、その牌を選ぶと待ちが出ます。テンパイ中は待ち牌とフリテンかどうかを表示します

### ルール

| 項目 | 内容 |
| --- | --- |
| 役 | 1翻〜役満までの一般的な役（タイトルの「遊び方・役一覧」に一覧） |
| ドラ | 表ドラ・カンドラ（カンするとすぐめくる）・裏ドラ・赤ドラ（各色の 5 を 1 枚ずつ、なしも選べる） |
| 鳴き | ポン・チー・明槓・暗槓・加槓。食いタン・後付けあり。喰い替えなし |
| ロン | ダブロンなし（頭ハネ）。フリテン（捨て牌・見逃し・リーチ後の見逃し）あり。槍槓あり |
| 流局 | 荒牌流局のみ（ノーテン罰符 3000点）。途中流局・流し満貫はなし |
| 連荘 | 親が和了るかテンパイで連荘。オーラスの親がトップなら終了（あがりやめ） |
| 終局 | 西入なし。残った供託はトップへ |

役満は複合しても数えますが、ダブル役満（四暗刻単騎・国士十三面など）はなしで 1 倍です。

### CPU

基本は牌効率（シャンテン数と受け入れ枚数）で切る牌を決め、リーチを受けたら現物・スジ・字牌などの安全な牌で守ります。そのうえで 3 人それぞれに打ち方の癖があります。

| 名前 | 打ち方 | 癖 |
| --- | --- | --- |
| ハル | 鳴き屋 | 役がありそうならどんどんポン・チー。手牌が一色に寄ってきたら混一色・清一色を狙う。リーチされても 2 シャンテンまでは押す |
| ナツ | リーチ一直線 | 役牌のポン以外は鳴かず、テンパイしたら必ずリーチ。リーチされても 1 シャンテン以上ならかなり押す |
| アキ | 慎重派 | 手が進む鳴きだけで、リーチがいると鳴かない。リーチされたら 1 シャンテンでもオリる。役があって 3 翻以上の手や、待ちが悪い手はダマテン |

癖の強さは `js/game.js` の `STYLES`（鳴き方・染め手・オリる目安・押す目安・ダマ）で変えられます。

### 保存

- 局のはじめごとに途中経過（点数・局・本場・供託）を保存します。タイトルの「続きから」で、その局のはじめから再開できます（牌の並びは新しく配りなおし）
- 設定と戦績（順位の回数）も保存します。`localStorage` のキーは `mahjong.` で始まります

## 構成

```
index.html     画面（キャンバス・ボタン置き場）
style.css      見た目（ボタン・タイトル・結果画面）
js/rules.js    ルール計算（シャンテン数・待ち・役・符・点数）。node でも動く
js/game.js     進行・CPU の思考・描画・操作
tools/test.js  rules.js のテスト（node mahjong/tools/test.js）
thumb.png      トップページ用のサムネイル
```

牌の絵はすべてキャンバスで描いています（画像ファイルなし）。`index.html#auto` を開くと 4 人とも CPU で高速に対局し続けます（動作確認用）。

リポジトリ全体のことや、他のゲームは [ルートの README](../README.md) を見てください。
