# くねくねスネーク（スネークゲーム）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/snake/）。エサを食べるたびに体が伸びていくヘビを操り、できるだけ長く生き残って高いスコアをめざすゲームです。

## 遊び方

- ヘビはまっすぐ進み続けます。向きを変えて赤い**エサ**を食べると体が 1 マス伸び、少しずつ速くなります
- 壁（「壁あり」のとき）・岩・自分の体にぶつかったらゲームオーバー
- エサを 5 個食べるごとに**金の星**が出ます。下のゲージがなくなる前に取ると大きな得点（早く取るほど高い）で、体が 2 マス伸びます
- 盤面をすべて埋めつくすとクリア
- 操作
  - パソコン：矢印キー / WASD で向きを変える、P / Esc でポーズ、Space / Enter でスタート
  - スマホ：画面のどこでもスワイプ（盤面の外の余白からでもよい）するか、下のボタン。指を離さずに動かし続けると続けて曲がれます
  - スマホのボタンは 2 種類から選べます（タイトル画面）：**十字ボタン**（上下左右を直接選ぶ）と、片手で遊びやすい**左右ボタン**（ヘビから見て左・右に曲がる）
  - パソコンでは盤面をマウスでドラッグしても曲がれます
  - 曲がる操作は 3 つまで先に入力しておけます（素早い U ターンもできます）
- 右上の ♪ で音のオン・オフ、左上の Ⅱ でポーズ

### 設定（タイトル画面）

| 項目 | 選べるもの |
| --- | --- |
| スピード | ゆっくり（得点 ×1）・ふつう（×2）・はやい（×3） |
| 盤面の端 | 壁あり（ぶつかると終わり）・通りぬけ（反対側から出てくる） |
| マップ | ひろば（何もない）・岩場（岩が置いてある） |
| 操作ボタン（スマホのみ） | 十字ボタン・左右ボタン |

ハイスコアは設定の組み合わせごとにブラウザに保存されます（`localStorage` のキーは `snake.` で始まります）。

盤面の大きさ・スピード・星の出かたは `game.js` の `N`・`SPEEDS`・`STAR_EVERY`・`STAR_TIME`、岩の配置は `makeRocks` で変えられます。

## 構成

```
index.html   画面（上の帯・盤面・十字ボタン）
style.css    見た目
game.js      ゲーム本体（ヘビの動き・エサ・入力・描画・音）
thumb.png    トップページ用のサムネイル
```
