# 鉄壁の砲台（タワーディフェンス）

このフォルダの `index.html` を開くと遊べます（公開版：https://mo-kazuya.github.io/MyGame/tank-defense/）。道を進んでくる戦車を、道ばたに建てた砲台で撃ち、基地にたどり着かせないように守るタワーディフェンスです。

## 遊び方

- 空き地（草地）をタップしてから下の一覧の砲台を選ぶと、そこに建ちます。先に一覧の砲台を選んでから空き地をタップしても建てられます（続けて何台も建てられます）
- 建てた砲台をタップすると、射程が表示され、**強化**（Lv3 まで）と**売却**（使った資金の 70% が戻る）ができます
- **Lv3 への強化では「型」を 2 つから選びます**（下の表）。ボタンを 1 回押すと説明が出て、もう一度押すと決まります
- 砲台ごとに**ねらい**（先頭・最後尾・最強・最速）を切り替えられます（電磁波は除く）
- 「▶ 出撃」を押すとウェーブが始まります。ウェーブの間も砲台は建てられます
- そのウェーブの戦車が全部出てきたら、倒し切る前でも「▶ 次を呼ぶ」で次のウェーブを呼べます。残っている戦車が多いほど**早期ボーナス**が増えます（危険も増えます）
- 戦車を倒すと資金、ウェーブを守り切るとボーナスがもらえます。さらに手持ちの資金の 5%（最大 $30）が**利息**として付きます
- 戦場の右下の**支援**ボタン：空爆（タップした場所を爆撃）・地雷（道に置く）・一斉射撃（8 秒間すべての砲台が倍の速さで撃つ）。使うと待ち時間が始まり、待ち時間は**ウェーブ中だけ**減ります
- 戦車が基地にたどり着くと耐久が減り（重戦車は 2、超重戦車は 10）、0 になったら負け
- 決められたウェーブをしのぐとステージクリア。残った耐久で ★1〜3 が付き、次のステージが遊べるようになります（ブラウザに保存）
- 右上の ×1 でスピード（×1・×2・×3）、♪ で音のオン・オフ、左上の Ⅱ でポーズ
- キーボード：1〜4 で砲台を選ぶ、Space で出撃（次を呼ぶ）、U で強化、A / B で Lv3 の型、T でねらい、S で売却、Q / W / E で支援、P / Esc でポーズ、+ / - でスピード

### 砲台

| 砲台 | 値段 | とくちょう |
| --- | --- | --- |
| 機関砲 | $50 | 連射が速い。装甲の厚い戦車には効きにくい |
| 大砲 | $100 | 山なりの砲弾で、着弾したまわりをまとめて攻撃 |
| 電磁波 | $80 | まわりの戦車をまとめて遅くする。装甲を無視して少しダメージ |
| ミサイル | $150 | 射程が長く、追いかけて当たる。1 発が重い |

### Lv3 の型

| 砲台 | A | B |
| --- | --- | --- |
| 機関砲 | 徹甲弾：装甲の 3/4 を無視 | 二連装：倍の速さで撃つ。射程は短い |
| 大砲 | 焼夷弾：着弾した所が 3 秒燃える（装甲を無視） | 長距離砲：射程がとても長いが、近すぎる戦車は撃てない |
| 電磁波 | 衝撃波：6 秒ごとにまわりの戦車を 1.2 秒止める | 弱体化：まわりの戦車の装甲を 5 下げる |
| ミサイル | 多弾頭：3 発に分かれて別々の戦車をねらう | 対装甲：体力の多い戦車ほど大ダメージ（最大 2.5 倍） |

組み合わせると強くなります。電磁波で遅くした（止めた）戦車には大砲が 1.3 倍効き、弱体化で装甲を下げると機関砲が重戦車にも通るようになります。

### 戦車

| 戦車 | とくちょう |
| --- | --- |
| 偵察車 | 速いが打たれ弱い。群れでやって来る |
| 軽戦車 | ふつうの戦車。少し装甲がある |
| 重戦車 | 遅いが体力と装甲が多い。機関砲はほとんど効かない |
| 超重戦車 | 最終ウェーブ（とウェーブ 10）に現れるボス |

装甲は 1 発ごとに威力から引かれます（どんなに装甲が厚くても威力の 1/4 は通ります）。そのため、重い戦車には 1 発の威力が大きい大砲やミサイルが効きます。

### ステージ

| ステージ | ウェーブ | 道 |
| --- | --- | --- |
| 1. 草原の一本道 | 8 | 1 本 |
| 2. つづら折りの谷 | 10 | 1 本（長く曲がりくねる） |
| 3. 挟み撃ち | 12 | 2 本（途中で合流） |
| 4. 最終防衛線 | 15 | 2 本（基地が真ん中） |

ステージ（道・岩・池・資金・ウェーブ数・戦車の強さ）は `game.js` の `STAGES`、ウェーブの中身は `makeWave`、砲台（Lv3 の型を含む）と戦車の強さは `TURRETS`・`TANKS`、支援は `SKILLS`、利息と早期ボーナスは `INTEREST`・`earlyBonus` で変えられます。

縦持ちのスマホでは、マップを対角線で折り返して縦長にして表示します（戦車は上から下へ進みます）。

